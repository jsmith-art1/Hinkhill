Team Smith HQ Work Orders
A small static app for Jim and Linda to create project requests for Justin from the Team Smith HQ page.

The requester includes:

Requester selection for Jim or Linda
Project area, timeline, and priority
Title, details, location, budget, and success criteria
Work order preview with copy, email draft, and print actions
Recent work orders saved locally in the browser
Open index.html in a browser to use it.

To send email drafts to a default recipient, set submissionEmail in app.js.
